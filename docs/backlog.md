# GLaDOS Robot — Backlog ошибок

## Найденные баги

### 1. LLM эхо-повтор "Лица: создатель" вместо нормального ответа
- **Симптом:** Модель отвечает только "Лица: создатель" или "Понял вас. Лица: создатель"
- **Причина:** `handle_vision` добавляла полное описание камеры как `user` сообщение, а `ContextBuilder` дублировал ту же информацию как `[vision]` system-контекст. Модель (qwen2.5:3b) путалась и просто эхо-повторяла face info.
- **Фикс:** `handle_vision` теперь отправляет `[наблюдение]` как триггер, описание только через system context.
- **Статус:** ИСПРАВЛЕНО.

### 2. Нет звукового вывода (TTS pipeline полностью молчит)
- **Симптом:** LLM генерирует текст, но аудио не воспроизводится. В логах нет ни одного сообщения от VoiceLoop, Speaker, TTS queue.
- **Причина:** INFO-логи не отображались из-за бага #5. После исправления #5 — TTS pipeline заработал.
- **Статус:** ИСПРАВЛЕНО (было следствием #5).

### 3. `python -m glados` — No module named glados.__main__
- **Симптом:** `python -m glados robot` не работает.
- **Причина:** Отсутствовал `src/glados/__main__.py`.
- **Статус:** ИСПРАВЛЕНО.

### 4. LLM эхо-повтор тега "[vision]" в ответах
- **Симптом:** Модель начинает ответы с `[vision]` — например: `[vision] Видно человека в очках...`
- **Причина:** Двойной источник: (a) ContextBuilder инжектировал `[vision] описание` в system message, (b) personality prompt содержал `Сообщения с [vision] — то, что ты видишь`. Модель выучила паттерн и воспроизводила тег.
- **Фикс:** ContextBuilder: `Сейчас ты видишь: {desc}`. Personality: убрана ссылка на `[vision]`.
- **Статус:** ИСПРАВЛЕНО.

### 5. Loguru фильтрует INFO-логи (показывает только SUCCESS+)
- **Симптом:** Все INFO-логи TTS pipeline не отображаются в консоли.
- **Причина:** `core/engine.py:55` — `logger.add(sys.stderr, level="SUCCESS")` на уровне модуля. Импорт из `cli.py` срабатывает до robot-команды.
- **Фикс:** `cli.py` для robot-команды: `logger.remove(); logger.add(sys.stderr, level="INFO")`.
- **Статус:** ИСПРАВЛЕНО.

### 6. Vision описания на английском языке
- **Симптом:** FastVLM генерирует описания на английском ("The image depicts a person wearing headphones..."), LLM вынужден переводить.
- **Причина:** VisionWorker.VISION_PROMPT на английском.
- **Влияние:** Лишняя нагрузка на маленькую модель (qwen2.5:3b), иногда кривой перевод.
- **Статус:** ОТКРЫТО.

### 7. ASR ложные срабатывания / галлюцинации
- **Симптом:** ASR распознаёт бессмысленные фразы: "И у меня слушаем", "я даже не знаю, чем не сам не нарисовать"
- **Причина:** Whisper base галлюцинирует на коротких/шумных фрагментах.
- **Статус:** ОТКРЫТО — нужен фильтр уверенности/длины.

### 8. LLM описывает картинку вместо саркастичного комментария
- **Симптом:** Модель отвечает на vision-события описательно ("Видно человека в очках и тёмном жакете...") вместо язвительных комментариев в стиле ГЛаДОС.
- **Причина:** Personality и autonomy tick prompt не давали достаточно чётких инструкций комментировать, а не описывать.
- **Фикс:** Personality: "Не повторяй описание — язвительно прокомментируй." Tick prompt: "Саркастично прокомментируй... Не описывай — комментируй."
- **Статус:** ИСПРАВЛЕНО.

### 9. FaceID не распознаёт создателя (creator)
- **Симптом:** В логах `Лица: 1 незнакомых` при наличии создателя перед камерой. Модель говорит "незнакомый человек".
- **Причина:** Вероятно порог распознавания или качество enrollment-фото. det_10g иногда даёт max score ~0.2 (ниже порога).
- **Статус:** ОТКРЫТО — нужна диагностика с debug-логами FaceID.

### 10. TTFT деградирует с ростом контекста
- **Симптом:** LLM TTFT: 0.81s → 7.84s → 13.42s → 19.50s — растёт со временем.
- **Причина:** Conversation store накапливал сообщения бесконечно. qwen2.5:3b на CPU O(n²) по длине контекста.
- **Фикс:** Добавлена обрезка контекста в AsyncBrain: system messages + последние 10 пар (user/assistant).
- **Статус:** ИСПРАВЛЕНО.

### 11. cv2.putText не отображает кириллицу (крокозябры в окне Vision)
- **Симптом:** Текст VLM описания в OpenCV окне отображается как нечитаемые символы.
- **Причина:** `cv2.putText` не поддерживает Unicode/кириллицу.
- **Фикс:** Три отдельных окна: Camera (живой поток), Snapshot (анализ + face bbox), VLM Text (PIL-рендер кириллицы на текстовую панель).
- **Статус:** ИСПРАВЛЕНО.

### 12. Логи не записываются в файл
- **Симптом:** Все логи идут только в stderr, после закрытия теряются. Нельзя посмотреть историю запусков.
- **Причина:** Не было файлового логирования.
- **Фикс:** `logs/YYYY-MM-DD_runNN.log` — файл на каждый запуск с DEBUG-уровнем. stderr остаётся на INFO.
- **Статус:** ИСПРАВЛЕНО.

### 13. Нет описаний лиц в контексте LLM
- **Симптом:** Модель видит "Лица: creator" но не знает кто это. При вопросе "Чьё лицо?" отвечает "человек с короткой шевелюрой".
- **Причина:** `face_names` маппил folder→display_name, без доп. информации для LLM.
- **Фикс:** Новый формат `FaceProfile(name, description)`. Описание инжектируется в контекст: "Распознанные лица: Создатель — Твой создатель. Молодой человек в очках..."
- **Статус:** ИСПРАВЛЕНО.

### 14. qwen2.5:3b генерирует бессмыслицу на русском
- **Симптом:** Модель выдаёт нелогичные фразы: "Болван же такой шуму несуёт", "не стоять на тропинке у бабушки", "Извиняюсь за путаницу... займусь этим моментом немедленно".
- **Причина:** qwen2.5:3b слишком маленькая для: русского + сарказм + vision контекст + roleplay ГЛаДОС.
- **Фикс:** Переключено на qwen2.5:7b.
- **Статус:** ИСПРАВЛЕНО.
